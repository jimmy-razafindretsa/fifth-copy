# #314 Rollup job: raw keystrokes into daily character and letter-pair stats

Date: 2026-11-17. Outcome: built (Builder); Deliver completes this entry.

## Decisions
- No new ADR. Follows 0008, 0011, 0016, 0021, 0024.
- Job `stats.rollup` (`rollupCharStats`, every minute, 200 oldest unrolled rows). One transaction per trace: the marker first (`updateMany ... rolledUpAt: null`), then one `INSERT .. ON CONFLICT` over `unnest` arrays per table.
- What a trace adds is the pure `traceIncrements` (engine `keyStats`, keys lower-cased, letter pairs only).
- A trace whose result does not count, or whose stored values cannot be replayed (codec, schema or engine rejects them: deterministic), is marked and skipped. Only a failed write leaves the trace for the next run.

## Gotchas
- The worker must not import `@/features/results` (index): it pulls the report UI and `next/headers` into the esbuild bundle. New `src/features/results/server.ts` exports `COUNTED_RACE` and `storedReplay`; `stats/queries/counted-where.ts` now imports from it.
- DB tests share the test database: `rollupKeystrokes(ctx, { only })` scopes a run to the test's typists.
