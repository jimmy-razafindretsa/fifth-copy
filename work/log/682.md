# #682 Race client: one typed RoomSocket test fake

- Date: 2026-11-03
- Outcome: `fakeRoomSocket()` in `src/features/race/client/testing/fake-room-socket.ts` replaces the hand-rolled `RoomSocket` fakes of `connect-seat.test.ts` (1) and `resume-key.test.ts` (3). Its object literal `satisfies RoomSocket` with no `unknown` cast; every `on*` is a `vi.fn` returning a recorded `Off` (`bound`, `offs`), and `deliver(event, payload)` fires the live listeners of an event.

## Decisions
- No ADR. Test-only; `RoomSocket` and the protocol are untouched.
- `satisfies` on the object literal (the Contract's C1), not a class `implements`: same compile-time guarantee, and the `vi.fn` members keep their mock types for assertions.
- The cleanup test's listener count is `probe.bound.length + 2`: bindRaceSocket bound on a probe fake, plus connectSeat's own two welcome listeners (handoff #214 C2, issued-key memory #656). A new binder listener needs no edit; a new connectSeat listener still does, on purpose.
- New depcruise rule `feature-testing-only-from-tests`: a module under `src/features/**/testing/` is imported only by `*.test.ts(x)` or other `testing/` modules. dependency-cruiser rejects `(.+/)?` as an unsafe regex, hence `^src/features/.*/testing/`.
- Lobby fakes (`lobby-store.test.ts`, `settings-form.test.ts`) left alone: already typed `RoomSocket` without a cast, and importing race's `testing/` from lobby would break `feature-public-api-only`. `store.test.ts`'s IoFactory fake is out of scope (card).

## Gotchas
- `npx vitest run src/features/race src/features/lobby` goes 1107 -> 1109 passed (1 skipped both): `race/components/imports.test.ts` and `race/no-three.test.ts` run one case per race source file, and the new module is one more file. No existing test's assertions changed.
- Payloads given to `deliver` are not parsed: tests pass only the fields the code under test reads.
