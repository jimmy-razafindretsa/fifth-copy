## Decisions (reviewed, accepted)
- `getRaceSeat` is a `"use server"` module so the client-reachable race index still builds (C9 and ADR 0001 keep the route on the index). Input is zod-parsed, the function only reads, and it returns the data the page already serves. Security note (low, not a blocker): advisory GHSA-24wh-92f8-rgf5.
- Store-reading leaves live in `src/features/race/seat/`, which keeps `components/` presentational (#558 C10).
- Every `RoomSocket.on*` returns its `Off`. This is not a wire change. The lobby ignores the return value.
- `RaceSeatLive` reads `mint` through a ref, so the action's cookie-set refresh does not open a second socket (one mint and one socket per visit).

## Gotchas
- `see.ts` has no filter for the known benign Flight `ERR_ABORTED` (e2e/fixtures.ts `isBenignFlightAbort`). It hits about 1 in 4 fresh-guest race visits, so re-run before you call it a failure.
- Bundle: `/race/[raceId]` is 238.5 kB. The shared baseline is about 226 kB and this route adds 12.7 kB. The remaining 11.5 kB has to cover #214 and #559.
- A transport drop more than 5 minutes after the mint reconnects with an expired token and lands in a terminal `bad-token` (#235).
