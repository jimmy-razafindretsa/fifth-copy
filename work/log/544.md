Date: 2026-10-07. Outcome: delivered (PR #620). Deliver verified C1-C3: grep finds the `AUTH_SECRET` literal (line 23); `scripts/visual-baselines.sh --check` exit 0, 6/6 @visual passed, no baseline diff; `scripts/check.sh` green except one timing test under load (passes alone, #600).

## Decisions
- No ADR (governing 0004). The script is now the local twin of the CI `visual` job: same CI-only, non-secret literals as `.github/workflows/ci.yml`, Postgres + Redis, `npm run build` then `npm run build:race`.
- The worktree `.env` is never forwarded into the container; build output stays redirected; no `set -x`.

## Gotchas
- Since #165 Playwright always starts the race server, so `--check` needs Redis and `services/race-server/dist` (not in `git archive`); `AUTH_SECRET` alone only fixes `next build`.
- If `src/env.ts` or the race server env gains a required var, update both `ci.yml` and this script.
- Docker must be running; a run takes several minutes.
