## Decisions
- ADR 0015 accepted by Deliver (roles/deliver.md 3b): same hook position and typed-error rule as ADR 0014, reader still serves APPROVED only, no runtime dependency, no schema or protocol change.
- The heuristic only approves or flags; `reject` comes only from the fake (tests) or the operator script. `statusFor` throws on anything other than approve/flag, so a broken moderator stores nothing.
- PENTEST (3 minors, operator side) fixed before Deliver: `approve` requires `--version`, `reject` deletes only the version it read and exits 1 naming `AVATAR_DIR` when no file was found. Re-checked by Deliver through the real CLI on the test DB.
