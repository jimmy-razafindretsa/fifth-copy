# #768 Restore the held card, cooldown and blur after a reconnect

Date: 2026-11-04. Outcome: built in the bundle #660 + #768 (lead #660, one `PROTOCOL_VERSION` bump to 10).

## Decisions
- No ADR (follows 0006, 0007, 0016). `welcome.bonus = {card, cooldownUntil, blurUntil}` (race ms, each null when none or over; the field is null outside a running race and for spectators), produced by `bonuses.bonusOf` (`services/race-server/src/rooms/bonus-step.ts`): cooldown end = `lastPlayedAt + COOLDOWN_MS`, clamped to `MAX_RACE_MS`.
- The store seeds `bonus` from it with the welcome's own clock offset (`t0 + ms - clockOffset`, as `bonus-hit`); no play in flight and no refusal after a (re)connect; `plays` never goes back. `watchBlurExpiry` lifts a seeded blur unchanged.

## Gotchas
- The server deals no second card while one is held, so only the welcome can bring a held card back: the e2e relies on that.
