# #565 Rival identity markers

Date: 2026-10-31. Outcome: delivered (Deliver verdict pass); every rival on the race card wears the allocator's ink and shape (`rivalIdentity`), twelve muted inks per theme, owner-approved (C6, 2026-10-31).

Decisions
- Two independent ink sets (light, Night shift) as raw hexes in the theme blocks (`--t-rival-N`, `--color-rival-N`); not `--brand-*`. Bible 3.1 table + rule "rival inks appear only on race-card markers, placards and scarves"; 14.3 notes the owner exception.
- C3 checks all 66 pairs: desks 1-12 put every ink on a circle. Linear sRGB -> Machado 2009 (severity 1) -> CIELAB D65 -> CIE76.
- `MARKER_SHAPES` is now an alias of the protocol `MARKERS` (same order and values).
