# #669 Board workflow: run board.ts on a GitHub runner (no card)

Date: 2026-10-24 (logged 2026-11-03 by card #683). Outcome: merged as PR #669 (commit e2e7791) without a card, Contract, HANDOFF or log, requested directly by the repo owner. Adds `.github/workflows/board.yml` (`workflow_dispatch`) so sessions whose GitHub proxy blocks GraphQL can still run `scripts/board.ts`.

## Decisions
- Inputs `op` (regex-checked), `args` (JSON array of strings), `body` (written to a file, argument `@BODY@`), `request_id` (in the run name). They reach the script only as env, never interpolated.
- Output: job summary, log, artifact `board-<request_id>` (`output.txt`, `exit-code.txt`).
- Follows `ci.yml` conventions: node 24, `npm ci`, a concurrency group; `permissions: contents: read`.
- No ADR: CI tooling, no architecture change.

## Gotchas
- `BOARD_TOKEN` (classic PAT, `repo` + `project`) first sat as a repo secret; #672 moved it to the `board` environment limited to `main`.
- Run logs are public: never send private text as `body`.
- It edited `.github/**` (a `touches:arch` hotspot) while #629 and #645 held that lock; files were disjoint, no behavioural drift (sweep, 2026-10-24).
