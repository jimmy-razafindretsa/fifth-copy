## M5a special-characters guide (C26-C29)

2026-11-19. `/guide` ("How to type it") is its own feature, `src/features/guide/` (static content, `index.ts`, light `client.ts` door for the keyboard map's deep links). Header nav, footer and the Dawn report tip's `GUIDE_HREF` point at `/guide`; bible 14.3 "How to type special characters".

- C27 honesty: the build had no Windows, macOS or ChromeOS machine, and main has no committed macOS keyboard fixture (#566's fixtures sit in unmerged PR #694). So **no pair is verified**: every layout/OS pair renders the empty state. The combinations in `content.ts` are candidates (`check: null`), filed for the owner to verify, never shown.
- OS: `Sec-CH-UA-Platform`, else the User-Agent (`CrOS`, `Windows NT`, `Macintosh`); Linux, Android, iOS and unknown agents get the unknown-OS fallback (all three systems per character). `?os=` and `?layout=` override; the layout defaults to the viewer's saved layout, else the locale's (`localeLayouts`).
