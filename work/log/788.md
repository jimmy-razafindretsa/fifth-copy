# #788 Teacher password reset: PasswordReset model and host-issued code

2026-11-04. The host of a lobby (a non-guest account) can issue a single-use, 30-minute reset code for a student who raced in any of their lobbies; only its Argon2id hash is stored and the row is the audit record.

- Migration `20261104001631_password_reset` (additive: one table, two indexes, two FKs). An extra index on `issuedByUserId` backs the `SET NULL` FK.
- Eligibility lives in `src/features/identity/queries/reset-eligibility.ts` (not `password-reset/` as the card sketched): the Prisma client is only allowed in `queries|actions|jobs`.
- Order inside `issuePasswordReset`: zod, viewer (absent/guest/not host, unknown room = `not-host`), `password-reset-issue` limit (refusals count), student lookup (one `not-eligible`), hash, insert.
- Guest merge: `guestHasNone("PasswordReset")` (subject or issuer), as for the recovery code: a guest can never own one.
- For R2: redeem the newest unused, unexpired row of the user (`@@index([userId, issuedAt])`), verify with `verifyPassword(normalizeResetCode(input), codeHash)`, bump `tokenVersion`.
