# #494 Landing shell: bible header and hero port

Date: 2026-10-05. Outcome: C1-C9 verified by Deliver (PR #515), 9 of 9 ticked. `/` now renders the bible header (monogram + "FIFTH COPY") and hero (halftone, 8° band, four `fcSpin` stars, kicker, wordmark, tagline, pitch) from `src/features/landing`. Both are async Server Components. Strings come from the new `src/i18n` `getT()` (English only).

## Decisions
- No ADR. On Night shift the kicker uses `var(--color-link)` (night-ink), because agit-red on the night ground is only 1.76:1. This is recorded as a bible 3.3 line.
- Brand marks are `next/image` from `public/brand/`. SVGs are auto-unoptimized, so `img[src="/brand/..."]` stays stable.

## Gotchas
- Next 16 deprecates `<Image priority>`. Deliver replaced it with `loading="eager"`.
- CSS modules scope the keyframes name (`…__fcSpin`), and Turbopack rejects `@keyframes :global()`.
- Until the hero gets its full height back (#99/#489/#497), star 1 sits behind the start of the pitch.
- `en` is `as const`, so `Messages` has literal types. #372 must widen the type before `fr.ts` can satisfy it.
- `var(--color-*)` resolves only when Tailwind emits the variable (work/log/16.md). The e2e probe catches a regression.
