# #693 Seat scene: stamps readable over the 3D room

2026-11-03. Over the 3D seat scene the scene-area stamps (the countdown's `НАЧАЛИ · GO`, overtake, passed, finish) keep their bible 7.3 ground made opaque (`--color-bg` instead of the 90% paper-ish mix), so the room never shows through them in light or Night shift.

- Decision: extend the stamp's own ground (7.3) rather than add a chip around it; one rule in the seat layout's "Over the scene" block, scoped to `[data-countdown]`/`[data-stamps]` stamps, so the `Stamp` primitive and every paper screen keep the 90% mix. Bible 14.3 "Over the scene" names it.
- Test: `e2e/race/scene.spec.ts` "#693 C2" (light and dark): an in-page MutationObserver audits every visible text under `[data-seat]` for an alpha-1 ancestor background below `[data-seat]` at each countdown digit, GO and the overtake stamp. The host runs with WebGL off (one scene per test); the page under test uses `?scene=pin` (pinned LOW, `data-scene-preset="low"`).
- Gotcha: the audit ignores opacity on purpose (a slamming stamp starts at opacity 0) and skips 1px screen-reader text; it must run in the observer callback, because GO lasts only 1.2 s and software WebGL makes page round trips slow.
