# #361 Bot typing model: level profiles, rhythm, errors, hesitation, bilingual names

2026-11-02. `nextBotKeystroke` is the real model behind #729's interface; `BOT_NAMES { fr, en }` live in the engine; the protocol derives `botLevelSchema` from `BOT_LEVELS` and re-exports `BOT_LEVEL_WPM`; the race server names bots by `settings.language`. `ENGINE_VERSION` 0.5.0. No wire change (`PROTOCOL_VERSION` unchanged: the enum values are the same).

Decisions:
- Stateless pipeline in `next.ts` (correction owed, pace, hesitation, error), one pure file per step; the profile stays data. `delayMs` is a float.
- Pace is normalised over the whole text (mean pace factor plus expected pauses), memoised per `chars` array in a `WeakMap`: the effective WPM lands on the target whatever the text's mix.
- Jitter: mean-one lognormal, sigma 0.3 (C2 needs CV >= 0.25; sigma 0.25 alone would sit at 0.253). Burst: common words `1 - 0.5 * burst`, slow words `1 + 0.3 * burst` (a small slow factor keeps C5's <= 10 % of long pauses elsewhere).
- `BotContext.language?` (engine-local `BotLanguage`) picks the rare letters; absent, both languages' rare letters count. #366 passes `settings.language`.
- `block` mode: the refused position is simply drawn again, so the observed wrong-key rate is `p / (1 - p)` (6.4 % for Recruit), inside C4's one point.
- Registry: a language change in a room with bots re-seats in the same MULTI so the names follow it (the `roster` broadcast already fires on `members`).
- Bible 2 gets a one-line extension for the bot-name pattern.

Measured (errors off, seeds 1-50, fr / en fixture): CV min 0.46/0.41 Recruit, 0.43/0.38 Clerk, 0.41/0.37 Officer, 0.40/0.36 Commissar, 0.39/0.35 Major; effective WPM within 3 % of every target; peak 10 s window 107 WPM (Major), far under the 220 cap; every trace, errors on in all four modes too, passes `analyseTrace`.

Gotchas: the fixture words count with `wordCount` (200 exactly); C3's "100 most common words" are the fixture's most frequent, ties shorter first, slow words removed so the two sets are disjoint.
