# #188 Race result and keystroke data model

- date: 2026-10-06 (Deliver)
- outcome: delivered, verdict pass; PR #570; contract 5 of 5 ticked by Deliver with evidence it ran.

## Decisions
- `ResultStatus.TIMED_OUT` (sixth value, builder): accepted. The engine ranks desks still `typing` when a race ends on TIMER (ADR 0007) and spec 13.1 stores a finish status per result; the Contract names five values but fixes only names, C5 counts enums. A superset avoids a second `touches:prisma` card. #189/#199 map typing-at-timer-end to `TIMED_OUT`.
- No new ADR; ADR 0008 gained one Context line naming #188.

## Review notes
- Migration `20261007030403_race_domain` is purely additive: CREATE TYPE/TABLE/INDEX plus 5 FKs from the new tables; no statement touches `User` or `Lobby`.
- Indexes: by race = `RaceResult(raceId, desk)` unique and `RaceKeystrokes` PK `(raceId, desk)` (leading `raceId`); by user = `userId` on both; purge = `RaceKeystrokes(createdAt)`. A user history query ordered by time (#311) would prefer `RaceResult(userId, createdAt)`; minor, add additively in that card if its plan needs it.
- onDelete: all five FKs `CASCADE` (checked in `pg_constraint` on the test DB), as the Contract requires.
- Keystrokes: gzip `Bytes` per (race, desk), `createdAt` indexed for the 30-day purge (#315), fits ADR 0008.
