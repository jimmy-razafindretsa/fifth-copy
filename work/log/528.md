# #528 Operator script to rename an offensive username

Date: 2026-10-06. Outcome: delivered (PR #538). Deliver verified C1 (`npx vitest run scripts/rename-user.test.ts` 9 passed on the card's test DB, plus a manual run: refuses without `--yes`, refuses a remote URL via db-guard, renames by case-insensitive username, stdout only `<id> <new name>`, old name no longer matches) and C2 (grep ok).

## Decisions
- No ADR (0004, 0009 followed). Accounts with a username get the new typist name as `username`/`usernameNormalized` too: C1 says "replaces the username", and leaving it would keep the offensive name stored and shown ("Comrade [username]"). Password, `tokenVersion`, sessions and relations are untouched; the student signs in with the new name, which the operator gives the teacher (moderation.md step 4).
- `db-guard.sh` runs on `DATABASE_URL` before any connection; its stdout is dropped so stdout carries only the result. Unexpected errors print only the error class name.

## Gotchas
- Lookup matches id, typist name or normalized username; more than one match refuses and asks for the id.
- `scripts/delete-user.ts` (#81) was not on main; the script follows `prisma/seed.ts` + db-guard instead.

## Follow-ups
none (forcing a new name choice at sign-in stays out of scope)
