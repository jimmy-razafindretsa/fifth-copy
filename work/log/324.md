# #324 Personnel file: Carte du clavier (PLAN DE LA MACHINE)

2026-11-17. The keyboard map ships on `/profile` between the key inventory and the attendance register: a layout switch over the four product layouts, a four-row board where each typed key carries a violet circle (how often) around a red core (share of errors), the row shares, and a legend.

Decisions: identity's layout module stays the only layout table; it gains each layout's number row (`numberRows`) and the locale default (`localeLayouts`, now also read by the race machine rows). Stats maps the key file's `byChar` onto a layout in a pure view (`stats/view/keyboard-map.ts`); the route passes the layouts in as data, so stats does not import identity. One client leaf holds the chosen layout; all four maps are computed on the server, so switching sends no request. Deviations recorded in bible 14.3.

Bundle: `/profile` 346.0 kB before, 346.8 kB after (+0.8 kB; the route-wide overrun is #986).
