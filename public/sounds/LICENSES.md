# Sound licences

Every file under `public/sounds/` is listed here (#243). Only CC0 1.0 or CC-BY 4.0 sounds are allowed; a
CC-BY sound carries its attribution text below. `src/features/race/client/audio/licenses.test.ts` reads
this table and the file sizes (each file <= 60 kB, the set <= 200 kB).

The current set is synthesised by `scripts/sounds.ts` (seeded noise and sine partials, no sample from
anywhere else), an original work of this repository dedicated to the public domain.
