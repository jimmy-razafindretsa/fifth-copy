## Decisions
- REPLAN option (a): `asleep` ranks with `typing | line-cut | expired` by frozen progress then accuracy (ADR 0007 ranking line, spec 4.1 rule 6); only `abandoned` (Reassigned, spec 4.4) is a separate last tier. No ADR change.
- `compareResults` returns literal -1/0/1 (never -0); one `Record<PlayerStatus, number>` tier table is the extension point.
- `placeOf` returns 0 for a desk not in the list (falsy sentinel, tested).
- `elapsedFor` JSDoc tells #166/#173/#189 to pass `state.lastT` for asleep/abandoned/expired/line-cut and race end only for a typing player at timer expiry.

## Gotchas
- `accuracy` is harsh on purpose: `total` counts Backspace, `correct` is net of undo (2 typed, erased, retyped = 2/6). Pinned by a table row; do not "fix" it in #190/#225.
- Desks must be unique within a race or the order is not strict.
- NaN progress/accuracy would compare as a tie; inputs come from `progress`/`accuracy`, which never return NaN.
- `progress` "finished -> 1" branch is not pinned independently (its only row has cursor == length); add a row if overlays (#194/#198) can finish with cursor != base length.
- Under load (avg 40+) `scripts/rename-user.test.ts` can time out in check.sh; passes alone and in CI.
