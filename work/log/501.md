# #501 CI runs DB-backed Vitest tests against Postgres

Date: 2026-10-06. Outcome: the `check` job has a `postgres:17-alpine` service, sets `DATABASE_URL` and `TEST_DATABASE_URL` (the same throwaway DB, like `e2e`), runs `scripts/test-db.sh` before `scripts/check.sh`, and an `if: always()` `Unit summary` step prints the Vitest totals from `.cache/check/unit.log`. The `describe.skipIf(!TEST_DATABASE_URL)` suites now run in CI.

## Decisions
- No ADR. The change is CI-only and follows ADR 0003: a throwaway service DB is prepared by `scripts/test-db.sh`. `scripts/check.sh` is unchanged.
- `scripts/ci-workflow.test.ts` finds the unit job by its `scripts/check.sh` step, not by the job name.

## Gotchas
- `check.sh` hides Vitest output on PASS and uses the dot reporter, so there is no per-file line to grep. The evidence is the summary step: `Tests  N passed (N)` with no `skipped` segment. The only skips in the unit suite are the DB describes (14 tests).
- Vitest colours its output on Actions, so strip ANSI codes before you grep the log.
- `env -u TEST_DATABASE_URL` does not reach the skip path, because `dotenv/config` reloads it from `.env`. Use `TEST_DATABASE_URL=` (an empty string).
