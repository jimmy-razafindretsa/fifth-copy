# #757 worktree.sh: skip browser-restricted ports

2026-11-03. Outcome: `scripts/worktree.sh` never writes a WHATWG fetch "bad port" (browsers and Next.js refuse them) into a card worktree's `.env`. Found on #697: `PW_PORT=6697`.

Decisions: the bad-ports list lives in the script (mirrored in `scripts/worktree-env.test.ts`). A bad `5000/6000/7000 + slot` port becomes `9000 + slot` (next safe port from there): deterministic, 9000-9999 holds no bad port, and the bad slots of the three kinds are disjoint (web 60, 61; Playwright 0, 566, 665-669, 679, 697; race none), so replacements never collide with each other or the normal scheme. Every other slot keeps its ports. The ready line and the `.env` read the same variables; `--env` prints the ready line on stderr so the test compares them.

Tests: `scripts/worktree-env.test.ts` "safe ports (#757)", slots 665-669, 697 (+0, 60, 61, 566, 679, 1697).
