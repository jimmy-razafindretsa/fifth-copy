# #660 Protocol key schemas accept every key the engine normalises and stores

Date: 2026-11-04. Outcome: built in the bundle #660 + #768 (one PR, `PROTOCOL_VERSION` 9 -> 10).

## Decisions
- No ADR (follows 0006, 0007). The wire's key rule is the engine's: `keySchema` = `Backspace`, or one code point after NFC, no unprintable code point, and a non-empty `normalizeKey` (now exported by `@fifth-copy/engine`). `e` + U+0301 passes; `Shift`, a lone combining mark, emoji and other characters the engine drops are refused (an astral emoji used to pass and was then ignored by the engine).
- `playerStateSchema.typed` entries: 1..16 typeable characters (`isTypeable` each), so `"..."` from a wrong `…` parses.

## Gotchas
- Control whitespace (tab, newline) normalises to " " in the engine but stays refused on the wire (control characters never cross it); the C3 property's domain is the typeable set, NFD forms, look-alikes and `\p{Zs}` spaces.
- A version bump refreshes `INTERNAL_HMAC_TEST_VECTOR` (body `v` and signature).
