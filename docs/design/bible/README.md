# Design bible bundle (Red Tape Game Screen Wireframes)

Imported as-is from the team's design export on 2026-10-04. **Every design decision follows `FIFTH_COPY_DESIGN_BIBLE.md`** (visual, motion, 3D, copy, UX). The bible's `/reference` means this folder.

- `FIFTH_COPY_DESIGN_BIBLE.md`: design source of truth. Section 16 maps each reference file; section 18 is the ship checklist.
- `*.dc.html`, `Fifth Copy *.html`, `*.js`: reference implementations. Open in a browser; port 1:1.
- `FIFTH_COPY_SPEC.md`: snapshot of the product spec. The canonical product spec is `docs/spec/fifth-copy-spec.md` (newer: e.g. the logo is the team's own design, not an AI draft).
- `FIFTH_COPY_PERF_AUDIT.md`: perf budgets and presets.
- `archive/`, `assets/`, `screenshots/`, `uploads/`: history, mood and source material (`uploads/Design.pdf` = art direction).

Do not edit reference files to fit code; change the code. New design decisions go into the bible in the same PR.
