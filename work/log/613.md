# #613 Voided races leave an open-ended Race row

2026-11-09. Outcome: a worker job `race.void` (src/features/results/jobs/void-stale-races.ts, every 10 min) ends each `Race` still open 2 h (`VOID_AFTER_MS` = `MAX_RACE_MS` + 1 h) after `startedAt`, with no result, as `endReason` VOID. Option (b) of the card: no wire change, the race server stays database-less.

Decisions: a late results post (outbox retry after the sweep) replaces the VOID end with the real one in `persistRaceResults`, so VOID never carries results and nothing is lost. `COUNTED_RACE` (results index) is the filter stats consumers use: `endReason` in ALL_FINISHED, TIMER. `getDawnReport` answers null (404) for a VOID race.

Gotchas: the job sweeps the whole table; DB tests use a fixed clock older than any real row, so other test files' fresh races are never swept.

Follow-ups: none.
