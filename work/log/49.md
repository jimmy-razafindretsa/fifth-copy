# #49 GitHub and Discord sign-in

2026-11-09. GitHub (`read:user`) and Discord (`identify`) register from optional env vars; profile() keeps id, login, avatar; no email-based linking; PKCE and state checked. OAuth sign-up screens the login with `isClean`, and the current guest merges in `events.signIn`. `/sign-in?error=<code>` picks a bilingual sentence per Auth.js code.

Decisions: the guest merge runs in `events.signIn`, not the `signIn` callback: Auth.js calls the callback before the account row exists. src/server cannot import features, so identity's `isClean` and `mergeGuestCookieInto` are registered by the Auth.js route (`registerOAuthSignInHooks`); unregistered names fail closed (generated name).

Gotchas: Playwright's web server carries placeholder OAuth apps (playwright.config.ts), so `/api/auth/providers` lists github and discord in e2e. Production needs `AUTH_GITHUB_ID/SECRET` and `AUTH_DISCORD_ID/SECRET` set in Railway (ADR 0019); without them the buttons stay hidden.

Open: Google stays on the error path. ADR 0009 names only GitHub and Discord, and `OAuthProvider` has no GOOGLE value, so adding it needs an ADR change and a `touches:prisma` card. The age line keeps the owner's Google wording, not C5's quoted sentence.
