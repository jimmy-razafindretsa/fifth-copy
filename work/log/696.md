# #696 Site header: two rows at phone width

2026-11-03. At <= 480px the site header (landing, waiting room, Dawn report, 404) is two rows, 110px tall at 375 (was 196 to 307px): row 1 brand + EN/FR + NIGHT SHIFT, row 2 guide link, guest docket, SIGN IN. CSS only (`src/features/landing/components/header.module.css`) plus a `docketName` class; from 481px nothing changes (1280 header pixel-identical to main). Bible 14.1 item 1 carries the phone rule.

Decisions:
- The nav is `display: contents` at <= 480px (as the NIGHT SHIFT form already is) so its items join the header's flex lines; a zero-height `::before` (`flex-basis: 100%`, `order: 2`) breaks row 1 from row 2. The `navigation "Site"` landmark is kept (aria snapshot, e2e `getByRole`).
- To fit French `QUART DE NUIT` at 375: 16px gutter, 28px monogram, 16px brand name, toggles and row 2 tracked at `.08em`.
- The docket is `flex: 1 1 0; max-width: max-content`: it grows to its own width and the name ellipses (max 96px) instead of wrapping the row.

Gotchas: CSS `order` puts the guide link (DOM first in the nav) on row 2, so at phone width Tab goes brand, guide, EN, FR, NIGHT SHIFT, docket, SIGN IN. With the 96px cap the name shows as `Comrade …` (the honorific alone is ~60px); the full name is in the lobby roll and the Dawn report.
