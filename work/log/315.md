# #315 Purge job: raw keystrokes after 30 days, letter-pair stats after 90

Date: 2026-11-17. Outcome: built (Builder); Deliver completes this entry.

## Decisions
- No new ADR. Follows 0008, 0011, 0024.
- Job `stats.purge` (`purgeKeystrokes`, every hour, well inside "at least every 6 hours"). Periods are the exported constants `RAW_KEYSTROKES_RETENTION_DAYS` and `LETTER_PAIR_RETENTION_DAYS`; a test parses `docs/privacy/retention.md` and compares.
- Each batch is one `WITH gone AS (DELETE ... LIMIT n RETURNING ...) SELECT count(*)` statement: atomic, so a crash between batches only leaves due rows for the next run. The 50-batch budget is shared by both tables (keystrokes first).
- Keystrokes go whether rolled up or not; the log field `neverRolledUp` counts the ones the rollup never saw.
- Privacy page: the keystroke period now reads in the present tense, and a letter-pair line (90 days) was added; visual baselines of `/privacy` change.

## Gotchas
- DB tests share the test database: `purgeExpiredStats(ctx, { userIds })` scopes a run to the test's typists.
