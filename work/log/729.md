# #729 Bot model interface in the engine (stub)

2026-11-02. The engine exposes the bot model's interface in `packages/engine/src/bots/`: `BOT_LEVELS`, `BotLevel`, `BOT_LEVEL_WPM`, `BotProfile`, `botProfile(level)`, `BotContext`, `BotAction`, `nextBotKeystroke(profile, ctx, rng)`, re-exported from `src/index.ts`.

Decisions:
- `nextBotKeystroke` is a stub: next expected character at `60000 / (targetWpm * 5)` ms, never an error, `rng` unused; `null` when the desk is not typing or at the end.
- `BOT_LEVEL_WPM` is a `Record<BotLevel, number>`, the same shape as the protocol's, so #361 can make the protocol re-export it.
- Profile `errorRate` already holds the per-level rates of #361 C4; `hesitation` and `burst` are 0..1 placeholders #361 tunes.
- `ENGINE_VERSION` unchanged (no scoring or text change); #361 bumps it.

Gotchas: the protocol still has its own `botLevelSchema`, `BotLevel` and `BOT_LEVEL_WPM` until #361 derives them; nothing re-exports both, so no clash. The stub's delay is constant, which the anti-cheat `regular-rhythm` rule would flag: #366's analyseTrace criterion (C5) needs #361's rhythm.
