# #986 First-load JS of every route back under the ADR 0018 budget, enforced in CI

2026-11-17. Every App Router route was over 300 kB gzip on main; all are now 135 to 200 kB, and CI fails a build above the budget.

Base `/_global-error` and `/_not-found` were measured with this card's `--all` (the old script refused routes with no page entry).

- Cause 1, about 190 kB on every route: the root layout imported `MergeStamp` from `@/features/identity`. Turbopack's inferred side effects (any top-level call, such as a zod schema) made it evaluate whole barrels, so 39 client components went into the layout chunk, along with zod and a `node:crypto` polyfill. Fix: package.json `sideEffects` (ADR 0025, proposed). Guard: `src/lib/side-effects.test.ts`.
- Cause 2, about 176 kB on `/settings` and `/design`: three settings pickers imported constants from `identity/schema.ts` (zod plus the reset-code helpers' `node:crypto`). They now read `identity/preferences/values.ts`.
- Gotcha: a bare import of a side-effect-free module is dropped. That is why the nextauth route's `import "@/features/identity"` went: identity's merge steps reach that graph through `identity/server`'s merge chain anyway.
