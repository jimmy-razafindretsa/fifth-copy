# #748 Harden on-screen keyboard detection on tablets (bundled in #235)

Date: 2026-11-03. Outcome: built in the #235 bundle PR. Unit 15/15, tablet.spec C2-C4 pass at E2E_TIMEOUT_SCALE=3.

## Decisions
- The end-of-window timer only checks coverage (no elapsed compare). A `pointerdown` on the typing surface while the race input has focus starts a new window.

## Gotchas
- The tablet C3 test holds the page's `performance.now` (the detection clock) across the tap and the resize, so a loaded machine cannot run the window out between two Playwright calls; it runs with `hasTouch`.
