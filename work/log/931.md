# #931 Personnel file read model

2026-11-13. `getProfile(viewer)` in `src/features/stats` turns the viewer's counted `RaceResult` rows into a typed `Profile` (series with 7-day average, gain, current 7-day speed and accuracy, per-language best/mean/count, streak, last 7 days). `src/lib/time.ts` holds `STATS_TIME_ZONE` and `dayKey`/`addDays` (America/Toronto, `Intl` only).

Decisions: four queries per call whatever the file size (latest 200, earliest 5, one aggregate per language), so totals, bests and the gain's start are whole-file exact. The moving average, current 7-day figures, streak and last-7-days counts read the 200 loaded results (exact unless a typist runs more than 200 races inside the window or the streak). Result day = `RaceResult.createdAt` in Toronto.

Gotchas: `buildProfile` is pure and takes an optional `totals`; fixtures are built through it, so they follow the definitions. Next: the page cards of #928 import `getProfile` and `profileFixtures` from `@/features/stats`.
