# #626 zod out of the `/` and `/lobby/[code]` first load

Date: 2026-10-25. Outcome: delivered (PR #674); both routes measure 150.8 kB gzip first-load JS (was 241.5), zod classic no longer in either first load.

## Decisions
- Embed messages (bible 15 postMessage) are parsed by hand-written guards (`parseClerkMessage`, `parseViewMessage`); `useEmbedBridge` takes a `parse` guard instead of a zod schema. These are client-side guards on same-origin iframe messages, not a server edge: server actions still validate with zod.
- The join form uses a zod-free copy of the protocol room-code helpers (`src/features/lobby/room-code-input.ts`), parity-tested against `@fifth-copy/protocol`. `joinByCode` still re-parses with the protocol. No ADR.

## Gotchas
- Any client `import { z } from "zod"` (or a protocol barrel import) costs ~91 kB gzip; check with `npx tsx scripts/bundle-budget.ts <route>` after `npm run build`.
- The lobby page reaches landing code through the `@/features/landing` barrel (`LandingHeader`).
