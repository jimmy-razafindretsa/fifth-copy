# #891 Rebalance e2e CI shards

## Root cause
1. The serial `matchmaking` project (workers 1) sorted last, so all 21 of its tests ran in shard 6.
2. Most `e2e/race/*` specs skip mobile and tablet at runtime (`viewport.width !== 1280`), but Playwright shards by test count including those skips, so the real desktop race runs all landed in the last shard.

## Fix
`.github/workflows/ci.yml` `e2e-shard` matrix: four suites, 10 jobs (parallel 5, race-desktop 3, race-small 1, matchmaking 1). `scripts/ci-workflow.test.ts` asserts the suites partition `npx playwright test --list` (1260 tests). No timeout raised, no spec touched.
