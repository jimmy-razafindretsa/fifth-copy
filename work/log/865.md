# #865 Personal card: WPM through the race graph with bonus dips marked

2026-11-10. `wpmSeries` (`@fifth-copy/engine`, `scoring/series.ts`) replays a trace and returns the
clean WPM at the end of each bucket (<= 60, >= 1 s each) with `wpm()`'s formula; the last point is the
scored clean WPM. `getRaceSeries` (`queries/get-race-series.ts`) reads only the viewer's own
`RaceResult` and `RaceKeystrokes` rows (both filtered on `userId`), replays on `storedEffectiveText`
with `baseLengthOf` for the clean count, ends at `durationMs`, and adds received-bonus marks; `null`
without a trace. `RaceGraph` is a section of `PersonalCard` (optional `series` prop), inline SVG.

Decisions: the series is a separate query called by the page next to `getDawnReport` (not a
`PersonalStats` field), so #864's model and specimens are unchanged. Marks follow the `RECEIVED` row
rule (an exemption on oneself is not received). Ticks and names use the `link` role (red on paper,
night-ink on Night shift, bible 3.3), dashed. The gzip trace decoder moved to `trace-codec.ts`
(shared with `decodeTrace`). Bible 14.4 "WPM graph" added.

Gotchas: the six `/design` full-page baselines change (`#results-personal-graph`). Seeded e2e races
post empty traces, so their cards read NO TRACE ON FILE.
