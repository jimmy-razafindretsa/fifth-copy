# #863 Dawn report action row: RACE AGAIN with the way out, and the guest's OPEN A FILE prompt

2026-11-10. The Dawn report's action row is now an ordered list from one pure function
(`reportActions` in `src/features/results/view/report-labels.ts`): a member of an open lobby gets
`RACE AGAIN` then `BACK TO THE FRONT DESK →`, everyone else the front desk only, and a guest member
one more entry, the 7.4 docket-row prompt with `OPEN A FILE →` to `/sign-up`.

Decisions: the viewer's guest flag comes from the route (`getViewer()`), passed to `DawnReportScreen`
as `viewerIsGuest`; `getDawnReport`'s model is unchanged. Bible 14.4 "Action row" extended.

Gotchas: the `/design` full-page baselines (`design-light.png`, `design-dark.png`) change with the new
`#report-actions` specimen. `PERSONNEL FILE` is one more list entry once a profile route exists (#311).
