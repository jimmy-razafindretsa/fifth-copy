# #31 Identity data model: User (MVP first migration)

Date: 2026-10-05. Outcome: delivered (PR #499); all six contract criteria verified by Deliver.

## Decisions
- No ADR. Follows ADR 0002 (schema folder, fix forward), 0003 (test DB), 0009 (no email, `isGuest`, `tokenVersion`, no Session/VerificationToken).
- First migration `20261005024851_identity_user` sets the convention: Prisma default table/column names, no `@@map`.
- Case-insensitive username uniqueness is app-computed: writers must set `usernameNormalized = normalizeUsername(username)`; the DB enforces `@unique` on that column only.
- `isGuest` defaults to `true` (fail-safe: a row created without the flag is never an account).

## Gotchas
- `features/identity/index.ts` re-exports server-only `@/server/auth`: client code imports `normalizeUsername` from `features/identity/schema`, never the index.
- Deliver probes: migration applied to a fresh empty schema (`?schema=deliver31`, dropped after); missing `typistName` rejected, duplicate `typistName` -> P2002, no `*mail*` column.
- The DB describe is skipped in CI `check` (no Postgres): see #501.
