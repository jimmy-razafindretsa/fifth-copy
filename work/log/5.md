## Gotchas
- A worktree without `node_modules` makes `npx` fall back to the parent checkout's install, and `check.sh` then fails on `types` and `unit` for no real reason. Run `npm install` in the worktree first, with `DATABASE_URL` exported (#456 tracks a fail-fast).
- C6 teardown: stop the server by PID (listener + npm) instead of the Contract's `pkill -f`, because other `next` processes may run from sibling worktrees. Same evidence.
- `deploy-smoke.sh` against a dead host prints status `000000` (curl's `000` plus the `|| echo 000` fallback). Cosmetic only, and the exit code is still 1.
