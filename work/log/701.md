# #701 Charge the lobby code budget once under concurrent first calls

- Date: 2026-11-02. Outcome: built (PR pending Deliver). 100 concurrent first `limitCode` calls of one IP on one code now all pass and spend the `lobby-codes` budget once; distinct-code guessing stays capped at 20 per 60 s, concurrently too.
- Decisions: ADR 0020 amendment (2026-11-02): `@fifth-copy/limiter` gains `admit(budgetKey, markerKey, rule, now)`, one Lua script (`ADMIT_ONCE_LUA`) that checks the marker, spends the budget and writes the marker atomically. `code()` drops from three Redis calls to two (admit, pair bucket). Keys, limits, subjects, TTLs and fail-open unchanged, so no pentest.
- Gotchas: the script touches two keys, so both must live on one Redis node (Railway Redis is single-node; Redis Cluster would need a hash tag). `count()` stays exported but `code()` no longer uses it.
- Follow-ups: none.
