# #342 Race text corpus: licences, English and French curation, teacher texts, review

Date: 2026-11-03. Outcome: built (Builder), C3 accent band flagged needs-replan.

## Decisions
- No ADR. Public domain (Project Gutenberg) and teacher texts only; film quotes out of v1 (`docs/texts/sources.md`).
- `sourceRef` is `files:<lang>:<12-hex hash>` of that language's content files, generated into `manifest.ts` as `CONTENT_VERSION` by `npm run corpus`.
- Every passage was checked as a verbatim substring of the fetched Gutenberg plain text named in its `source` (after `normalizeTypeable`, `_` dropped, `--` as `-`). EN 96 passages / 18 works, FR 88 / 12.

## Gotchas
- Re-run `npm run corpus` after any content edit: the content test compares the hash.
- C3's 60 % accented-word band is not reachable with verbatim prose (best sentence-aligned window over 12 French books: 0.54), and its jq regex lacks a closing `]`.
