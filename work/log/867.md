# #867 Personal card: errors by key and the one tip

2026-11-10. `keyErrors` (`@fifth-copy/engine`, `scoring/key-errors.ts`) replays a trace with
`applyKeystroke` and charges each accepted press to the character under the cursor; a Continue-mode
backspace that undoes an error takes it back, so the error total always equals the replay's `errors`.
`getPersonalReplay` (`queries/get-race-series.ts`) now returns the WPM series and the viewer's missed
keys from one read of their own rows (`getRaceSeries` wraps it). `missedKeys` (view/keys.ts) ranks,
`pickTip` / `coachingFrom` (view/tip.ts) choose one tip of a closed list (clean, special, key,
accuracy, steady). `CoachingSections` renders both sections under the graph.

Decisions: "special" = any character outside printable ASCII (French letters, « », €). With no
trace the tip comes from the stored accuracy (100 % = clean). The guide link goes to `/#how` (the
header's guide target) until #388 ships the guide route. Bible 14.4 "Errors by key" and "Order of
the day" added.

Gotchas: an error corrected with backspace in Continue mode is not a miss (the engine's count). The
six `/design` full-page baselines change (`#results-personal-keys`). e2e seeds a trace through the
internal route (`Desk.trace`, `raceTextOf` in e2e/results/helpers.ts).
