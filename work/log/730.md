# #730 Lobby roll portraits: avatar cells behind lobby membership

Date: 2026-11-11. Outcome: built (Builder PR); Deliver to verify.

## Decisions
- No ADR. Path: the web reads the viewer's approved avatar version at mint (`getAvatarUser`) and puts it in the race token as a display-only `avatar` claim (`number | null`, absent = null); the race server stores it on the seat and emits `Member.avatar = { userId: sub, v } | null` (bots always null, refined in the schema). PROTOCOL_VERSION 18; the internal HMAC test vector re-signed for v18.
- The route stays the only gate (ADR 0014, 0022): the wire carries an address, never bytes; a spectator or any non-mate gets 404 and the cell shows the initials.
- `PortraitCell` stays in the lobby (the ranking keeps its own table cell); initials from the seat ring's `initialsOf`.
- Bible 14.3 gains "Roll portraits (extension, #730)".
