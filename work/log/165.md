# #165 Race server: Socket.IO handshake, waiting-room join/leave, POST /internal/rooms (HMAC), 30-player proof

Date: 2026-10-05. Outcome: delivered (PR #513). Deliver verified all eight contract criteria. Pen test: 0 blockers, 0 majors, 2 minors.

## Decisions
- No ADR. Follows ADR 0006 (handshake order: version, then token, then room; HMAC over `${timestamp}.${rawBody}`, checked before the body is parsed), 0008 (the registry owns every Redis key), 0009 (the room comes only from the token's `lobby` claim) and 0012.
- `registry.join` runs in the `connection` handler, not in the middleware. A client that drops between the two never gets a `disconnect`, so joining in the middleware would leak its desk. The middleware only reads.
- `app.ts` `createRaceServer` is the composition root. Tests boot it on port 0, and `main.ts` only wires the signals.

## Gotchas
- A reused local `npm run dev:race` keeps its own `WEB_ORIGIN`. Playwright overrides it to its base URL only when it starts the server itself.
- The CI `visual` job starts the race server too. It is a container job, so its Redis host is `redis`.
- Deliver probe: `dist/main.js` with a socket connected, then SIGTERM. The client got `disconnect` in 9 ms and the server exited 0 in under 0.2 s.
