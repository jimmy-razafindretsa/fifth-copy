# #969 Site header grade tag

Date: 2026-11-16. Outcome: built in one PR. An account's header docket ends with its grade tag (OFFICER / OFFICIER), part of the `/profile` link and of its name; guests and visitors unchanged.

## Decisions
- No ADR. Follows 0001, 0007, 0009, 0010, 0016, 0021. Bible 14.1 item 1 extended (band role, 11px, 3px 7px), 14.3 left-out list updated.
- `getRank` (stats, server-only `server.ts`): one `raceResult.aggregate` over `countedWhere`, then `rankFor`. The landing never imports stats: routes compose it through `src/app/_components/site-header.tsx` (`SiteHeader`, `headerGrade`).
- The header waits at most 50 ms (`GRADE_GRACE_MS`) for the grade beside the avatar read, so it lands in the shell (no layout shift); slower reads stream into their own Suspense boundary; a failed read draws nothing.
- The visible name is aria-hidden and one sr-only span carries the whole link name (flex items otherwise add a space before the comma).
- From 481px a graded name ellipses past 160px (at 200px the 1280 French row had 0 px slack locally and wrapped in CI); at <= 480px the tag hides, the link still says the grade.

## Gotchas
- For an account `/` is the Home menu (no site header, bible 14.5): C6 is checked at `/welcome` and `/profile`, plus the Home docket's rank at `/`.
- At 768 and 1024 the header already wraps without the tag: C5 asserts the tag adds no row.
