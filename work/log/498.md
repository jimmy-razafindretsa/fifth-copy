# #498 Lobby layout: FORM 5-L settings docket, invite COPY, START placement

Date: 2026-11-02. Outcome: built (UI, full). The lobby store keeps `settings` (welcome + every `settings` broadcast), a read-only `FORM 5-L` docket shows every setting in words, the room docket gained an `INVITE | COPY` row, and START sits under the settings docket in a dockets column.

Decisions
- One room docket, not two: the invite row goes in `RoomCodeDocket`'s `children` slot, so the code prints once. `InviteDocket` has a `links` slot for #121.
- `SettingsDocket` is driven by `SETTING_ROWS` (key, value in words, optional `when`). Each row renders `controls?.[key] ?? value` inside its `dd`, which is the seam for #110 and #114.
- The French header is `FORMULAIRE 5-L`, as `FORMULAIRE 5-R` already is. French "none" is gendered (`AUCUNE` lettre, `AUCUN` bot).
- Under reduced motion the hold token is 0 ms, so COPIED stays until the button blurs.
- A refused room (error phase) shows no settings docket.

Gotchas
- The `.ink` recipe is copied from `race/components/hud-docket.module.css`, because CSS modules don't cross features. Lifting it into the Button primitive is a chore for later.
- The width media queries sit at the end of `lobby.module.css`. Placed earlier, `.row { display: grid }` would override the phone `display: none` on the invite row.
- The invite status is `role="status"`, not `aria-live`. The #107 e2e selects `main [aria-live="polite"]` strictly.
- `see.ts` opens a guest context. The host views came from a throwaway Playwright driver (screenshots + axe, three widths, both themes).

Follow-ups: none filed.
