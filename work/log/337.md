# #337 Personnel file grade ladder

2026-11-16. Under the hero's four figures `/profile` shows `ÉCHELLE DES GRADES · SELON TA MOYENNE` with the way to the next grade (`51,4 / 70 MPM → COMMISSAIRE`, `GRADE MAXIMAL` at the top), the five grades as an ordered list of chips (passed on ink, held on red with `aria-current`, ahead outlined) and the red progress bar (a named `progressbar`), for accounts and guests alike.

Decisions: `GradeLadder` (`stats/components/grade-ladder.tsx`) is a server component that draws a `RankStep` from `rankFor(profile.service.meanWpm)` (#945) and the catalogs' `landing.clerk.ranks`; no threshold lives in it or the catalogs, no query is added. The reference's gold outline on the last chip is not legal on newsprint, so it is a 4px double ink rule (padding trimmed to keep the size); bible 14.3 records it.

Gotchas: the spoken current grade (`Officer, current grade`) lowercases the catalog name with the locale, so a rank name must stay a plain capitalised phrase.
