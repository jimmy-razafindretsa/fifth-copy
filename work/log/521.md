# #521 First-load JS budget script

2026-10-06. Outcome: `scripts/bundle-budget.ts '<route>'` prints `<route> <n> kB gzip (budget 250)` from the build manifests and exits 0 under / 1 over / 2 unknown route (ADR 0013 budget), because Next 16.3's `next build` prints no size column.

Decisions:
- Sum = `rootMainFiles` (page/build-manifest.json) + every `/layout` and the `/page` `entryJSFiles` (page_client-reference-manifest.js), deduped. Polyfills (nomodule) and not-found/global-error entries excluded.
- gzip level 9 via Node zlib, decimal kB.

Gotchas:
- Node's zlib gives ~1.2 kB more than Python gzip / `gzip -9` on the same 10 files (252.6 vs 251.2-251.4 kB for `/lobby/[code]`): stay well clear of the line, do not argue a 1 kB margin.
- `/lobby/[code]` and `/` are over budget today (shared root + layout set): the script correctly exits 1.
