# #781 Move Railway production from sfo to us-east

Date: 2026-11-09 (preparation). Outcome: runbook and ADR line ready; the move itself runs in a weekday 22:00-06:00
America/Toronto window (owner decision 2026-11-04).

## Decisions
- Region is set per service in the Railway dashboard (Settings > Scale > Regions), id `us-east4-eqdc4a` (US East Metal).
  Not in `services/race-server/railway.json`: Config as Code is deprecated, stops being read on 2026-12-01 and covers
  only the race-server. IaC (`.railway/railway.ts`) would need a dependency and an ADR.
- Three volumes migrate (Postgres 5 GB, Redis 5 GB, avatars 1 GB capacity): downtime per volume; race-server has none.
- Backups before the move: Railway volume backups plus an off-volume `pg_dump` (a volume wipe deletes its backups).

## Gotchas
- `sfo` is a legacy region, absent from the current picker: a rollback by region goes to `us-west2`.
- Take the "after" counts before any smoke race (a race writes rows).
