# #154 MVP wire contract: protocol v2, race token, deps, env, lobby stubs

Date: 2026-10-05. Outcome: C1-C8 verified by Deliver (PR #502), 8 of 8 ticked. `@fifth-copy/protocol` v2 fixes the waiting-room wire (room code, handshake, `welcome`/`roster`, reject reasons), the race-token claims and the internal `POST /internal/rooms` + HMAC spec with a shared test vector. Web signs race tokens (`src/server/race-token.ts`), the race server verifies them (`services/race-server/src/socket/race-token.ts`, every failure = `bad-token`). Lobby API exists as `NotImplementedError("#103")` stubs.

## Decisions
- No ADR proposed. Formats follow ADR 0006 points 5-6 and ADR 0009; `avatar` claim and `spectator` role deferred (adding them bumps `PROTOCOL_VERSION`).

## Gotchas
- `RACE_TOKEN_SECRET` is now required (>= 32 chars) by both processes: an old `.env` with the 22-char placeholder fails at startup; regenerate with `openssl rand -hex 32`. CI jobs that boot the web app carry a throwaway value.
- Web `RACE_SERVER_INTERNAL_URL` / `NEXT_PUBLIC_RACE_SERVER_URL` default to `http://localhost:4000`: set them explicitly in production.
- C3's `npm ci --ignore-scripts` wipes the Prisma client: run `npx prisma generate` after it.
- `jose` 6 is ESM-only; the race-server bundle resolves it as an external from the root `node_modules`.
