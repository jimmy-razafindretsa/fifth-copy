# #220 Error modes: Continue overstrike, Block machine jam, backspace and e2e

- Date: 2026-10-22
- Outcome: delivered on the light pipeline (no Explorer BRIEF). Contract `2e88b82c2585`: C1-C8 verified and ticked, `verdict: pass` on the first cycle. Block jams the teleprinter (red X, slot, space bar and outlines) and holds the cursor; Continue strikes the character and moves on; Backspace takes it back unless the host turned it off.

## Decisions (reviewed, accepted)
- C5 "same race text": texts are random per race, so both races press a key that is wrong for index 0 of their own text.
- The engine's verdict is read once, in `client/prediction.ts` (`wrong` = its `errors` grew; `jammed` = Block and `wrong`). The store, `selectMachineProps` and `TypingMachineLive` only carry it.
- #559's pop replay is fixed by a pop stamp `typedAt` in the prediction: a refused Block key keeps it, a Backspace clears it.

## Gotchas
- Block with `backspace: false`: a Backspace is a counted press, so it releases the jam (cursor and errors unchanged). #110 disables that control in Block mode.
- The C7 guard is a regex: it misses forms like `Array.from(text)[i] === key`. Review new comparisons by eye.
- Bundle: `/race/[raceId]` 246.5 kB, `/lobby/[code]` 241.5 kB (budget 300, ADR 0018).

- #654 (discovered, correctness): the race store ignores the `settings` broadcast, so a typist seated before a host change keeps the old error mode.
