# #214 Countdown and GO stamp

- Date: 2026-10-16
- Outcome: delivered on the light pipeline (no Explorer BRIEF). Contract `697785e8eda2`: C1-C8 verified and ticked, `verdict: pass` on the first cycle. The host's START moves every member to `/race/<raceId>`, the seat view counts 3-2-1 on the server clock, then shows the `НАЧАЛИ · GO` stamp, and `data-phase` turns `running` at GO.

## Decisions (reviewed, accepted)
- `bindRoomSocket` takes `{ lobbyId, storeResumeKey }`. The race module's `storeResumeKey` is passed in from the lazy `import()`, because #536 keeps race values out of the lobby's first load.
- The 10 s fallback lives in `parkSocket`, so a parked lobby socket also closes when the seat view never connects (phones). `connectSeat` closes it after its own welcome. The server keys members by user and counts sockets per user, so the parked socket never adds a desk.
- GO is scheduled at `race.t0` from a `countdown` and from a `welcome` in `countdown`. There is one GO per countdown, and unbind cancels it.

## Gotchas
- Without parking, the C4 spec fails on a `line-cut` frame (Deliver checked this with parking disabled).
- Bundle: `/race/[raceId]` is 239.9 kB, which leaves 10.1 kB for #559. `/lobby/[code]` is 241.5 kB.
- The countdown spec is desktop-only and sets its own viewports. Run it with `--workers=1`.
