# #828 Google sign-in

2026-11-09. Google OAuth ships beside GitHub and Discord (owner decision): `OAuthProvider.GOOGLE` (additive migration `20261109205019_oauth_provider_google`), provider registered from optional `AUTH_GOOGLE_ID/SECRET`, ADR 0009 amended (0014 host list too).

Decisions:
- Scopes `openid profile`, PKCE + state, never linked by email; the authorize URL is pinned (`accounts.google.com/o/oauth2/v2/auth`) so a press needs no discovery request; the callback still discovers Google's token endpoint.
- profile() keeps `sub`, `given_name` and `picture`. Google has no pseudonymous login, so only the first name seeds the typist name (full and family names dropped).
- The Google button now follows its env vars like GitHub and Discord (it no longer shows unconfigured and lands on the error banner).
- Picture import allows the exact host `lh3.googleusercontent.com`.

Gotchas: Google is OIDC, so Auth.js links it with `type: "oidc"`; the sign-in event already accepts both. Owner step: create a Google OAuth web client with redirect `<app>/api/auth/callback/google` and set the two Railway variables.
