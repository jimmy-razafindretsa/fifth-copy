# #351 Text generator: real sentences, random words, exact word count, difficulty

Date: 2026-11-03. Outcome: built, PR open, awaiting Deliver.

## Decisions
- No ADR (0001, 0006, 0007, 0008 hold). The engine's rare-letter set is exported as `RARE_LETTERS` (no behaviour change, ENGINE_VERSION stays 0.5.0).
- Content files are bundled through a generated `corpus/manifest.ts` (`npm run corpus`, drift-checked in `content.test.ts`): the generator stays pure, with no file system at runtime.
- Passages 12-80 words: the 42 seed sentences under 12 words were continued with their works' next lines (checked against Project Gutenberg where available), never invented. Milton's "Heaven of Hell" fails `isClean`, so the opening of Paradise Lost replaces it.
- Frequency lists (5000 words each) are counted from public-domain Project Gutenberg novels (books listed in each file), so no third-party list licence applies. That suits the owner's rule: public-domain literature only.
- Band thresholds are per language (French words run longer), about a third of each corpus per band.

## Gotchas
- `isClean` runs on whole passages: a mild word ("Hell") refuses the passage. Curators of #342 will meet it.
- Words mode carries 19th-century vocabulary (for example "bade"); rare archaic words drop out because a word must appear in several books.

## Follow-ups
none

## Deliver (2026-11-03)
- Content check against the real texts (Project Gutenberg, Wikisource, theatre-classique.fr): every French passage and every English passage that was continued past its seed sentence was compared with the source. 8 passages were corrected to the source's exact contiguous text: Sign of the Four (statement turned into the original question), Twelfth Night (2.5 letter wording, "thrust upon 'em"), Hamlet ("Therefore, since brevity..."), Midsummer Night's Dream (no longer skips Hermia's line), Verne ("Ainsi donc..."), Scapin (no longer skips Scapin's line between Géronte's), La Rochefoucauld (two unrelated maxims replaced by maxim 31 alone), Rimbaud ("ces cafés", Gutenberg 29302).
- Frequency lists: a naive recount over the Gutenberg ids recorded in each file reproduces about 95 % (en) and 89 % (fr) of each list, so they are self-derived, not a copied third-party list.
