Date: 2026-10-06. Outcome: delivered (PR #569). Deliver verified C1-C7: `npx vitest run packages/engine` 114 passed, boundaries and typecheck:workspaces clean, C7 greps ok; 8 mutants (reducer and text rules) all killed.

## Decisions
- No ADR (implements 0007). `text` must arrive normalised; the reducer indexes `text[cursor]` and only normalises `key`.
- Readings accepted against the Contract and spec 4.3: Continue finishes when the cursor reaches the end by any key (Block only on a correct key, C4); C6 counter identity holds exactly on backspace-free traces and net of backspace undo otherwise (the only reading compatible with C5); `wordCount` counts tokens with a letter or digit; an empty text rejects every keystroke (same reference).

## Gotchas
- Rejected keystrokes return the SAME reference: `t < lastT` is dropped, so #173 must clamp `t` before calling `applyKeystroke`.
- A multi-character non-Backspace key (e.g. `"Shift"`) counts as one wrong press: the protocol edge (#557) must accept one character or `"Backspace"` only.
- `« »` map to `"` and `€` is dropped, which conflicts with the R174 heatmap row and the spec 14 drill.
