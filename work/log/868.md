# #868 Seat view: NEW HOST stamp during a race

2026-11-11. The seat view shows `NEW HOST: <NAME>` when the host's desk is gone for good during a race (or the host leaves the ended room), and the promoted typist starts the next race.

Decisions:
- The notice is one more `StampKind` (`new-host`) in the #232 queue (`src/features/race/client/stamps.ts`): held `NEW_HOST_SHOW_MS` (slow 600 ms x 5 = 3 s, test-pinned to tokens.css), replaced at once by any stamp arriving while it shows; it waits its turn behind one. Ink tone (contract C2), not the lobby's red.
- `reduceRace` takes `new-host` in every phase for the host flag and your role; the notice only in `countdown`, `running`, `ended`. Unknown desk: same state.
- Strings: one `NEW_HOST` object per catalog, shared by `lobby.newHost` and `race.stamps.newHost`. No wire change.

Gotchas: the e2e waits the real 2-minute grace in CI (12 s with `RACE_FAST_CLOCK=1`); guests type a key every 10 s so the idle rule never kicks them, and the lane is polled every 200 ms so the 3 s stamp is not missed.
